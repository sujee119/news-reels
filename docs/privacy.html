Privacy Policy

Last updated: 18 October 2026

Reel Uploader is a personal automation tool used by its author to publish short videos to the author's own accounts. It has no other users.

Information it accesses

When authorised, the application requests a single Google permission, https://www.googleapis.com/auth/youtube.upload, which allows it to upload videos to the YouTube channel that granted the permission. It does not read your videos, comments, analytics, subscriber data, or profile information.

Information it stores

An OAuth refresh token is stored as an encrypted secret in the author's own private build configuration, so uploads can run without a person present. Video files, titles and descriptions generated by the tool are stored in the author's own repository and on the destination platforms.

Information it shares

None. No data is sold, transferred, or disclosed to third parties. The only parties involved are the author and the platforms the author uploads to.

Retention and removal

The refresh token is kept until it is revoked. Access can be withdrawn at any time at Google account permissions, which immediately prevents further uploads.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be sent to the developer contact address listed on the application's Google Cloud consent screen.
